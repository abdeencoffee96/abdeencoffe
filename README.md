# Abdeen Coffee — Landing Page

صفحة هبوط واحدة متجاوبة (عربي/إنجليزي) لـ بن عابدين / Coffee Makers Barista.

## الملفات
- `index.html` — الصفحة كاملة (HTML + CSS + JS في ملف واحد)
- `bg.jpg` — صورة الخلفية

## قبل الرفع على GitHub
افتح `index.html` وابحث عن الروابط التالية واستبدلها بروابطك الحقيقية:

| الرابط | ابحث عن |
|---|---|
| إنستغرام | `https://instagram.com/abdeencoffee` |
| فيسبوك | `https://facebook.com/abdeencoffee` |
| واتساب | `https://wa.me/966500000000` |
| خرائط جوجل | `https://maps.app.goo.gl/8sJcRnkzjNVXhoyN9` |

## النشر على GitHub Pages
1. أنشئ Repository جديد وارفع الملفين (`index.html` و `bg.jpg`) بنفس المجلد
2. من إعدادات الـ Repo: Settings → Pages → اختر Branch: `main` و Folder: `/root`
3. بعد دقيقة أو دقيقتين رابط موقعك يصير جاهز على:
   `https://USERNAME.github.io/REPO-NAME/`
